# Chouquette Glass — visual target

Version 2.1 was rebuilt from the author's 2023 screenshots rather than from the
appearance of another modern Discord theme.

The visual priorities are:

- The wallpaper must remain clearly visible through the whole application.
- Discord is covered by a dark navy veil, not opaque charcoal panels.
- The server rail is dark translucent glass.
- The channel / DM sidebar is translucent blue/navy glass.
- The central chat is only lightly tinted so the wallpaper stays prominent.
- The selected DM uses a broad muted blue rectangle.
- Navigation and header icons use bright cyan/turquoise.
- Message text is near-white and uses Baloo Bhaijaan 2 when available.
- The composer is a wide rounded, dark transparent bar.
- Embeds are translucent blue glass cards; Discord's colored left embed stripe
  is preserved.
- Date separators use a cyan line and a small cyan/blue pill.
- Hovering a message adds only a subtle cyan wash.

This file intentionally avoids copying personal/private content from the old
screenshots into the repository.
